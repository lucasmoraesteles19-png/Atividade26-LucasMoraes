## 📌 Sobre o repositório

Este repositório foi criado para armazenar e organizar as atividades desenvolvidas durante as aulas de Python, com foco na criação de **interfaces gráficas e programação**.

Aqui estão reunidos exercícios práticos que ajudam a desenvolver conhecimentos em Python, trabalhando com janelas, botões, campos de texto, listas e outros elementos de interação.

## 📂 Organização

O repositório contém:

- **📁 Atividades:** pasta com os exercícios desenvolvidos, reunindo as atividades até a número 10.
- **📸 Imagens:** registros dos programas em funcionamento, demonstrando os resultados de cada exercício.
- **🐍 Códigos Python:** soluções desenvolvidas durante as atividades, utilizando conceitos de programação e interfaces gráficas.

## 🛠️ Tecnologias utilizadas

| Tecnologia | Utilização |
|---|---|
| Python | Linguagem utilizada no desenvolvimento dos exercícios. |
| Tkinter | Biblioteca utilizada para criar interfaces gráficas. |

## 🎯 Objetivo

O principal objetivo deste repositório é registrar minha evolução no aprendizado de Python, colocando em prática os conteúdos estudados em sala de aula e desenvolvendo pequenas aplicações com interfaces gráficas.
